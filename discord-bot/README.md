# STAKEOUT — Discord Bot

Провижининг-скрипт: одним запуском создаёт всю структуру сервера из
[блюпринта](https://claude.ai/artifact/E4Ed6468Ww3oifvrCMoQs7) — роли, категории,
каналы и права доступа. Безопасно перезапускать: всё, что уже существует по имени,
пропускается.

## 1. Требования

- Node.js 18+ ([nodejs.org](https://nodejs.org))
- Уже созданный (пусть даже пустой) Discord-сервер STAKEOUT

## 2. Создать бота

1. Открой [discord.com/developers/applications](https://discord.com/developers/applications) → **New Application** → назови (например `StakeOut Ops`).
2. Вкладка **Bot** → **Reset Token** → скопируй токен, он понадобится ниже. **Никому не показывай и никуда не публикуй.**
3. Там же включи **Privileged Gateway Intents**: `SERVER MEMBERS INTENT` и `MESSAGE CONTENT INTENT` (пригодятся будущим ботам — музыке, XP, тикетам).
4. Вкладка **OAuth2 → URL Generator**:
   - Scopes: `bot`, `applications.commands`
   - Bot Permissions: на первое время проще всего выдать `Administrator` — потом можно сузить.
5. Скопируй сгенерированную ссылку внизу, открой её в браузере, выбери свой сервер STAKEOUT и подтверди приглашение.

## 3. Узнать Server ID (Guild ID)

Discord → Настройки пользователя → Расширенные → включить **Режим разработчика**.
Затем ПКМ по иконке сервера → **Копировать ID сервера**.

## 4. Настроить и запустить

```bash
cd discord-bot
npm install
cp .env.example .env
```

Открой `.env` и впиши:

```
DISCORD_TOKEN=токен_бота_из_шага_2
GUILD_ID=id_сервера_из_шага_3
```

Запуск:

```bash
npm run provision
```

Скрипт выведет в консоль каждую созданную роль/категорию/канал. Полный прогон — секунды-минуты в зависимости от лимитов Discord API.

## Что создаётся

Все названия ролей, категорий и каналов — в `config.js` (единый источник для провижининга и бота).

- **Роли персонала**: Владелец, Администратор, Модератор, Помощник
- **Звания (лестница опыта)**: Новичок → Сталкер → Ветеран → Стрелок → Охотник → Гроза бандитов → Мастер Зоны → Легенда Зоны
- **Роли доступа**: Политика, Другие игры + отдельная роль на каждую из 12 игр (названия игр — в оригинале)
- **Категории**: НАЧНИ ЗДЕСЬ, СООБЩЕСТВО, СЕРЬЁЗНЫЙ РАЗГОВОР (гейт: Политика), 12 игровых категорий (гейт: своя роль на каждую), ДРУГИЕ ИГРЫ (гейт: Другие игры), ЗВАНИЯ И СОБЫТИЯ, ПОДДЕРЖКА, ПЕРСОНАЛ (гейт: роли персонала)

## Что до сих пор нужно руками в Server Settings

Discord API не даёт (или не стоит) автоматизировать это:

- Включить **Community mode** (нужен для Rules Screening, Welcome Screen и Stage-каналов)
- **Verification Level** → High
- Загрузить лого сервера (иконка + баннер)
- Возрастной гейт на `#без-цензуры` (Discord включает это автоматически при `nsfw: true`, но стоит перепроверить в настройках канала)

## Постоянный бот — `bot.js`

В отличие от разовых скриптов (`provision.js`, `scripts/*.js`), `bot.js`
должен работать постоянно, пока сервер живёт — закрыл окно консоли, все
фичи ниже перестают отвечать.

```bash
npm run bot
```

Что он делает при старте и дальше:

- **Роли** — публикует в `#выбор-ролей` два выпадающих списка (игры,
  Политика/Другие игры); выбор сразу выдаёт/снимает роль.
- **Правила** — публикует текст правил и лестницу наказаний в
  `#правила`.
- **Приветствие** — публично здоровается с новым участником в `#добро-пожаловать`
  после того, как он пройдёт Rules Screening (не сразу на вход, если
  Community mode с скринингом включены).
- **Обращения** — панель с 4 кнопками в `#создать-обращение`; открывает модалку,
  создаёт приватный канал в категории `🎫 Обращения`, кнопка закрытия удаляет
  канал.
- **XP и звания** — очки за сообщения (кулдаун 60с) и за время в войсе
  (тик раз в минуту, АФК-канал не считается); при достижении порога меняет
  роль-звание и объявляет это в `#рейтинг`. Хранится в `data/xp.json`
  (не в гите — это рантайм-данные, не код).
- **Свой голосовой** — вход в голосовой «➕ Создать канал» создаёт личный
  канал в той же категории и переносит туда; канал удаляется, когда
  опустеет.
- **Антирейд** — при входе нового участника проверяет возраст аккаунта
  (< 7 дней — алерт) и всплеск одновременных входов (5+ за 10с — алерт с
  пингом персонала). Оба алерта идут в `#подозрительные`, автобанов/киков нет —
  решение всегда за человеком.
- **Музыка** — текстовые команды в `#музыка` (`!play`, `!skip`,
  `!pause`/`!resume`, `!stop`, `!queue`), без слэш-команд и их деплоя.
  YouTube и SoundCloud напрямую, Spotify-ссылки резолвятся в название и
  ищутся там же. YouTube-экстракция в целом хрупкая штука (это Discord
  вообще, а не баг этого кода) — если перестанет работать, SoundCloud-ссылки
  как запасной вариант.

## Разовые скрипты — `scripts/`

- `npm run setup-automod` — создаёт три правила нативного Discord AutoMod
  (слова ненависти + алерт в `#логи`, спам-упоминания, инвайт-ссылки
  кроме `#самопиар`). Безопасно перезапускать — пропускает уже созданные
  правила по имени.
- `node scripts/purge-channel.js <имя-канала>` — удаляет все сообщения в
  канале (например, после тестов). Работает только с сообщениями младше
  14 дней — ограничение самого Discord API.
- `npm run translate-to-russian -- --dry-run` — показывает план перевода
  названий живого сервера с английского на русский; без `--dry-run` —
  применяет (переименование на месте, ID сохраняются). Безопасно
  перезапускать.
